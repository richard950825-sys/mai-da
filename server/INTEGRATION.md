# 服务端集成说明

完整的用户流程与工具使用说明见根目录 [MCP_INTEGRATION.md](../MCP_INTEGRATION.md)，部署与凭据设置见 [运行说明](../docs/DEVELOPMENT.md)。

当前实现包含真实麦当劳 MCP 传输、动态工具 Schema 验证、公开商品资料的模型辅助分类、套餐多轮配置、实际券价比较、独立订单确认、访客会话以及持久化 IP 日额度。

供应商地址固定为官方 HTTPS 地址并禁止跟随重定向。模型仅能给出经过验证的偏好或候选顺序，不能创建工具权限、发起交易或补造价格/营养事实。账单和用户令牌不进入模型对话。

营养记录按唯一名称和可验证份量匹配，缺失值保留未知；糖不由碳水推算。官方原始记录与已核实份量证据不匹配时，禁用该证据，不作为运行时兜底数据。

实际下单有单独的开关、报价归属、CSRF、一次性确认和提交前核价。发生网络不确定结果时，不自动重试创建订单。测试中的供应商数据只存在于测试文件和注入的测试传输内。
